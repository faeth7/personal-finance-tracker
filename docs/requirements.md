# Personal Finance Tracker – Requirements

## 1. Project Overview

The Personal Finance Tracker is a web application that helps users manage their personal finances. Users will be able to record their income and expenses, organise transactions into categories, create monthly budgets and monitor their savings goals.

The application will provide a dashboard showing important financial information, helping users understand their spending habits, manage their money and make better financial decisions.

## 2. User Personas

### Persona 1 – Aisha (University Student)

- **Age:** 20
- **Occupation:** University student
- **Financial situation:** Receives student finance and has a part-time job.
- **Main problem:** Struggles to manage irregular income and keep track of everyday spending.
- **Needs:** Wants to record expenses, monitor monthly spending and avoid exceeding her budget.

### Persona 2 – Tom (Young Professional)

- **Age:** 25
- **Occupation:** Graduate working full-time.
- **Financial situation:** Receives a regular monthly salary and wants to save money.
- **Main problem:** Finds it difficult to understand where his money goes each month.
- **Needs:** Wants to monitor his income and expenses, set savings goals and track his progress.

## 3. User Stories

1. As a user, I want to create an account and log in so that my financial information is private.
2. As a user, I want to add income transactions so that I can track the money I receive.
3. As a user, I want to record expenses so that I can monitor my spending.
4. As a user, I want to edit and delete transactions so that I can correct mistakes.
5. As a user, I want to organise transactions into categories so that I can understand where my money goes.
6. As a user, I want to view my monthly income and expenses so that I can understand my financial situation.
7. As a user, I want to create monthly budgets so that I can control my spending.
8. As a user, I want to set savings goals so that I can work towards specific financial targets.
9. As a user, I want to view charts and reports so that I can understand my spending habits.
10. As a user, I want to search and filter transactions so that I can find specific financial records.

## 4. MoSCoW Priorities

### Must Have
- Users must be able to create an account and log in.
- Users must be able to add, edit and delete income and expense transactions.
- Users must be able to organise transactions into categories.
- Users must be able to view their income, expenses and remaining balance.
- Users must only be able to access their own financial information.

### Should Have
- Users should be able to create monthly budgets.
- Users should be able to set and monitor savings goals.
- Users should be able to search and filter transactions.
- Users should be able to view monthly financial summaries.

### Could Have
- Users could view interactive charts and graphs.
- Users could export financial reports as CSV files.
- Users could receive notifications when approaching their budget limits.

## 5. Non-Functional Requirements

### 5.1 Security
- User passwords must be securely hashed and never stored as plain text.
- Users must only be able to access their own financial information.
- The application must validate user input to prevent invalid or malicious data.

### 5.2 Performance
- The dashboard should load within 3 seconds under normal operating conditions.
- The application should process normal user requests without noticeable delays.
- The database should efficiently retrieve transactions and financial summaries.

### 5.3 Usability
- The application must have a clear and easy-to-use interface.
- The application must work on desktop, tablet and mobile devices.
- Common tasks, such as adding a transaction, should require minimal steps.

## 6. Project Scope

The initial version will focus on personal income and expense tracking, transaction management, user accounts and basic financial summaries.

More advanced features, such as interactive charts, report exports and budget notifications, can be introduced in later development stages.
